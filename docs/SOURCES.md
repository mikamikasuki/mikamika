# Asset and data sources

- Profile: <https://github.com/mikamikasuki/mikamikasuki>, fetched revision `d4ca626cf2f955065b3aa669955ae5389c8ba475`. The original README and all three SVGs are preserved in `assets/source/`. The purple/blue/pink banner, typing phrases, waves, original pixel cloud paths and introduction text are retained; their scene coordinates and colors are adapted for the composite canvas. Embedded source filter references use the `scene-` prefix.
- Layout references: user-supplied `reference/p1-idle.png` and `reference/p2-bubble.png`. The GitHub heading and pencil are excluded from the generated scene. Reference thumbnail photos are not extracted or published as travel content.
- State boundaries: `us-atlas` 3.0.1, `states-albers-10m.json`, redistributed from the US Census Bureau 2017 cartographic boundary shapefiles. <https://github.com/topojson/us-atlas>, <https://www.census.gov/geographies/mapping-files/time-series/geo/carto-boundary-file.html>. License preserved in `vendor/us-atlas-LICENSE`. Projection is Albers USA with AK/HI insets; county data is not shipped.
- Fonts: `@fontsource/nunito` pinned in package-lock.json, upstream <https://github.com/googlefonts/nunito>. SIL Open Font License copied into `vendor/Nunito-OFL.txt`. Outlined SVG text and local WOFF2 use the same weight files; no system fonts are redistributed.
- Rank: <https://github.com/anuraghazra/github-readme-stats/blob/master/src/calculateRank.js>, retrieved 2026-10-06; unchanged file and MIT license in `vendor/`. Statistics definitions are documented in `statistics.md`.
- Test images: `tests/fixtures/landscape.png` is a synthetic geometric landscape, generated for tests. It is not a photograph or travel record. Tests derive colored variants for multiple layers; fixture builds are separate from dist.

GitHub Pages workflow versions were checked against the official repositories on 2026-10-06. Checkout 7.0.1, setup-node 7.0.0, cache 6.1.0 and the official configure-pages v5 / upload-pages-artifact v4 / deploy-pages v4 actions are pinned to full commit SHAs. Deployment structure follows <https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages>.

The travel journal layout was informed by the travel page in [mikamikasuki/mika](https://github.com/mikamikasuki/mika/tree/708cb069d5a48336989732b690f5039a253ff413/docs/travel): its standalone map, photo stack and album navigation.
